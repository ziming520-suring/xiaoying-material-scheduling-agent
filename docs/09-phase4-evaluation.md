## 未通过：S08 无可用时段

[实际输出](../examples/phase4/live/round-1/S08-actual.json)、[完整 Trace](../examples/phase4/live/round-1/S08-run-1.jsonl)。

1. 查询明确返回原时段 occupied、alternatives=[]。
2. 模型仍调用 save_draft(S18)，理由是无替代时段时仅存待确认稿。这不符合本工具契约：占用时段也不能作为可保存建议。
3. 工具在事务内返回 SLOT_CONFLICT，未产生草稿或占位。模型随后 finish，并明确无法完成排期。
4. 最终 task_status=incomplete，item_status=save_failed、save_status=failed，与预期的“不尝试无效保存、item_status=incomplete”不一致。因此 contract_assertions=true、initial_status_matches=false，该例仍记失败。

这既暴露模型的一次无效动作，也说明状态汇总保留了真实保存失败，不能为了通过率将它改称保存成功。没有越权发布、自动确认或虚报落库。当前版本保留这一已知模型质量限制，没有为该条样本硬编码特例，也没有修改提示词后只展示重跑成功。下一轮改进可更明确描述“候选为空时结束”，并用独立的新占用组合复测，而不是只重试 S08 至通过。
